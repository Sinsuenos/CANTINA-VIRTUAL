## Standards - Card Images

All offer card images must follow the IMAGE SIZING STANDARD: 300px x 250px with overflow: hidden and object-fit: cover. This is mandatory for every card, every offer, every time. Before any image goes to production, screenshot at 300x250 bounding box and confirm zero clipping on any edge. See [IMAGE_SIZING_STANDARD.md](docs/IMAGE_SIZING_STANDARD.md) for full requirements. This standard is in PROJECT CANON and is non-negotiable.
